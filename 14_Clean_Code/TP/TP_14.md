Sebagai konteks, fungsi di bawah ini menampilkan rincian pesanan di modal dan jika klik konfirmasi, sistem akan menyimpannya.

```javascript
function fetchOrderDetails(orderId, token) {
    fetch(`https://example.com/api/order/${orderId}`, {
        headers: {
            'Authorization': token
        }
    })
    .then(response => {
        if (!response.ok) {
            throw new Error('Failed to fetch order details');
        }
        return response.json();
    })
    .then(order => {
        // Display order info
        const modal = document.getElementById('orderModal');
        const detailsDiv = modal.querySelector('#orderDetails');
        detailsDiv.innerHTML = '';

        const header = document.createElement('h3');
        header.textContent = `Order ID: ${order.id}`;
        detailsDiv.appendChild(header);

        const status = document.createElement('p');
        status.textContent = `Status: ${order.status}`;
        detailsDiv.appendChild(status);

        // Show modal
        modal.style.display = 'block';

        // Setup close button
        const closeBtn = modal.querySelector('.close');
        closeBtn.addEventListener('click', () => {
            modal.style.display = 'none';
        });

        // Setup confirm button
        const confirmBtn = modal.querySelector('#confirmOrderBtn');
        if (order.status === 'Delivered') {
            confirmBtn.style.display = 'none';
        } else {
            confirmBtn.addEventListener('click', () => {
                confirmOrder(order.id, token);
            });
        }
    })
    .catch(error => {
        console.error('Error:', error);
    });
}
```

## Deskripsi Program
Program ini digunakan untuk mengambil detail pesanan dari API berdasarkan **orderId** dan menampilkannya ke dalam modal pada halaman web. Jika pesanan belum berstatus **Delivered**, sistem akan menampilkan tombol konfirmasi yang dapat digunakan untuk memperbarui status pesanan ke server.

Beberapa perbaikan yang dilakukan pada proses refaktorisasi antara lain:
1. **Separation of Concerns & SRP (Single Responsibility Principle)**:
   - Fungsi besar `fetchOrderDetails` dipecah menjadi beberapa fungsi kecil dengan tanggung jawab spesifik:
     - `fetchOrder`: Mengambil data dari API.
     - `renderOrderDetails`: Menampilkan konten detail pesanan ke dalam modal.
     - `setModalVisibility`: Mengontrol buka/tutup tampilan modal.
     - `setupModalActions`: Menangani *binding event listener* untuk tombol aksi.
2. **Penggunaan Async/Await**:
   - Rantai `.then()` yang berpotensi menjadi *callback hell* diganti dengan sintaks `async/await` yang membuat alur kode asinkronus dapat dibaca seperti kode sinkronus (linier dan bersih).
3. **Pencegahan Memory Leak (Kebocoran Memori)**:
   - Penggunaan tombol konfirmasi sebelumnya rentan terhadap penumpukan event listener jika fungsi `fetchOrderDetails` dipanggil berulang kali. Perbaikan dilakukan dengan menduplikasi tombol (`cloneNode`) sebelum menambahkan event listener baru, sehingga listener lama otomatis dibersihkan bersama elemen lama yang diganti.
   - Penambahan opsi `{ once: true }` pada tombol tutup modal agar *listener* otomatis dihapus setelah modal ditutup.
